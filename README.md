# pixel-lab
## Star Academy: Club Tryouts

`star-academy.html` is a classroom game for grade 6 EFL in one file. Open it in Chrome or Edge on the smart board and tap **⛶ Full screen**.
- Target language: *Are you good at ___ing? / Yes, I am. / No, I'm not. / I'm good at ___ing. I want to join the ___ club!*
- 6–10 pairs, optional student names, 4 club tryout games (15 s each), Lucky Cards, auto-balancing, Club Championship with spinning wheel.
- Teacher buttons (top right): ⏸ pause · ⏭ skip · 🔊 sound · ↩ undo last pair · ⟲ restart.
- Keyboard (testing): D F J K for piano lanes, ← → for the catcher.
